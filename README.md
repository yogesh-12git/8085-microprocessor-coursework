# 8085 Microprocessor — Academic Coursework

This repository contains academic coursework and reference images related to the 8085 microprocessor and number representation.

## Topics Covered

- 1's complement and 2's complement
- 8-bit addition and multiplication
- 8-bit division
- 16-bit addition, subtraction, multiplication, and division

## Repository Contents

The files in this repository illustrate microprocessor arithmetic operations and related coursework exercises.

## Purpose

This repository serves as an academic reference for learning microprocessor fundamentals, arithmetic operations, and number representation.
